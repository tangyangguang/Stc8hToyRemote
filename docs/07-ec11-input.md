# EC11 输入

本文记录 controller 侧 EC11 的最终接入方式和维护边界。

## 引脚

| 信号 | 引脚 | 说明 |
| --- | --- | --- |
| EC11 A | P1.1 | 旋转 A 相 |
| EC11 B | P1.0 | 旋转 B 相 |
| EC11 SW | P5.4 | 中键，低电平有效 |

对应定义在 `controller/src/board_pins.h`。

## 采样架构

EC11 A/B 使用 Timer0 固定周期中断采样，采样周期约 0.5ms。ISR 只做最小工作：

```text
读取 A/B 电平
调用 drv_ec11_scan_delta_small_isr
把 delta 累加到 s16 累积器
```

主循环只消费累积 delta，不直接解码 A/B 相位。显示刷新、无线发包和配置模式逻辑不得反向影响 EC11 采样节拍。

## 编码参数

默认配置：

| 项 | 值 |
| --- | --- |
| 基础库 API | `drv_ec11` small ISR API |
| `DRV_EC11_SMALL_STEPS_PER_DETENT` | `4` |
| `DRV_EC11_SMALL_REVERSE` | `0` |
| delta 累积器 | `stc8h_s16` |

累积器必须保持 `s16`，避免快速旋转时溢出后方向或速度跳变。

## 快转加速

正常控制模式启用一档快转加速：

| 相邻有效 detent 间隔 | 速度步长 |
| --- | --- |
| `<= 15ms` | `5` |
| `> 15ms` | `1` |

配置模式禁用加速，EC11 每个有效 detent 只调整 1 个单位，避免配置值跳变。

## 中键语义

中键长按计时使用 Timer0 的 0.5ms 运行时 tick 换算，不依赖主循环刚好 10ms
调用一次 UI slice；无线发包等待只能推迟事件处理，不能拉长 5 秒阈值。

| 操作 | 条件 | 动作 |
| --- | --- | --- |
| 短按 | 正常控制界面 | 刹车并清零速度 |
| 双击 | `Lxxx` 丢链界面，两次按下间隔约 10ms..0.5s | 进入手动扫频 |
| 双击 | 非 `Lxxx` | 忽略 |
| 长按 5 秒 | 正常控制界面且按下前速度为 0 | 进入配置模式 |
| 长按 5 秒 | 正常控制界面且按下前速度不为 0 | 只清零速度，不进入配置模式 |
| 长按 5 秒 | 配置模式 | 保存配置并退出 |

中键在配置模式中也用于切换配置项；具体流程见 `docs/04-logic-flows.md`。

## 排查顺序

如果 EC11 手感异常，按以下顺序检查：

1. P1.1/P1.0 原始电平是否随旋转跳变。
2. Timer0 ISR 是否仍按固定周期运行。
3. `drv_ec11` small ISR API 和 detent 参数是否与默认配置一致。
4. delta 累积器是否仍为 `s16`。
5. 主循环消费和显示刷新节拍是否过低。
6. 快转阈值是否需要按实际手感微调。

不要把 EC11 解码放回主循环，也不要把显示刷新频率当作编码器采样频率。
