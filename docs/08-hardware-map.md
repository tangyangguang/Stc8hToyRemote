# 硬件映射

本项目沿用既有 STC8H1K08 玩具遥控器和接收机 PCB。`legacy/` 只用于确认接线和可观察行为；最终实现以本文件和各端 `board_pins.h` 为准。

## 公共 nRF24L01

| 信号 | 引脚 | 说明 |
| --- | --- | --- |
| CE | P1.6 | nRF24L01 CE |
| CSN | P1.2 | nRF24L01 CSN |
| SCK | P1.5 | SPI group 0 |
| MOSI | P1.3 | SPI group 0 |
| MISO | P1.4 | SPI group 0 |
| IRQ | P3.2 | nRF24L01 IRQ，引脚保留；应用轮询 `STATUS` |

## Controller

| 功能 | 引脚/通道 | 逻辑 |
| --- | --- | --- |
| EC11 A | P1.1 | 旋转 A 相 |
| EC11 B | P1.0 | 旋转 B 相 |
| EC11 SW | P5.4 | 中键，低电平有效 |
| 转向电位器 | ADC11 / P3.3 | 归约为 `0..180` 舵机角度 |
| 前进/后退 | P3.7 | 低电平有效输入 |
| 灯光 | P3.6 | 低电平有效输入 |
| 蜂鸣器 | P3.5 | 低电平有效输入 |
| 独立刹车 | P3.0 | 低电平有效，刹车但不清速度 |
| Fn | P3.4 | 低电平有效，请求/显示电压 |
| TM1637 CLK | P1.7 | 数码管时钟 |
| TM1637 DIO | P3.1 | 数码管数据 |

## Receiver

| 功能 | 引脚/通道 | 逻辑 |
| --- | --- | --- |
| 灯光 | P3.5 | 低电平亮，安全态关闭 |
| 蜂鸣器 | P3.6 | 低电平响，安全态关闭 |
| LED | P3.7 | 高电平亮，用于生命周期状态 |
| RF 频道 + | P3.0 | 低电平有效；默认构建关闭频道维护键 |
| RF 频道 - | P3.1 | 低电平有效；默认构建关闭频道维护键 |
| AT8236 IN1 | P3.3 / PWM7_2 | 前进 PWM，默认约 20.03kHz |
| AT8236 IN2 | P3.4 / PWM8_2 | 后退 PWM，默认约 20.03kHz |
| 辅助 PWM | P5.4 / PWM6_2 | 与 AT8236 共用 PWM-B 频率；来自 `aux_pwm`，controller 默认发送 0 |
| 舵机 | P1.0 / PWM1P | 50Hz 舵机 PWM |
| 电池电压 | ADC1 / P1.1 | 按请求低频采样并回传 |

## 输出安全态

receiver 掉线、射频错误或收不到合法控制包时：

```text
P3.3/PWM7 duty = 0
P3.4/PWM8 duty = 0
P5.4/PWM6 duty = 0
P3.5 灯关闭
P3.6 蜂鸣器关闭
P1.0 舵机回中
```

刹车命令与安全态不同：刹车时 AT8236 IN1/IN2 同时输出 100% duty；安全态下两路均为 0。
