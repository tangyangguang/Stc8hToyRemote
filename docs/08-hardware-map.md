# 旧硬件映射

本项目沿用旧项目硬件。旧工程只作为需求线索来源；以下表格记录可观察到的引脚事实，新实现仍按 `Stc8hBase` API 和本项目协议独立设计。

## 公共 nRF24L01

| 信号 | 引脚 | 说明 |
| --- | --- | --- |
| CE | P1.6 | nRF24L01 pin 3 |
| CSN | P1.2 | nRF24L01 pin 4 |
| SCK | P1.5 | SPI group 0 |
| MOSI | P1.3 | SPI group 0 |
| MISO | P1.4 | SPI group 0 |
| IRQ | P3.2 | 支持外部中断，当前阶段仍轮询状态 |

## Controller

| 功能 | 引脚/通道 | 当前处理策略 |
| --- | --- | --- |
| EC11 A | P1.1 | 已用 `drv_ec11` 采样 |
| EC11 B | P1.0 | 已用 `drv_ec11` 采样 |
| EC11 SW | P5.4 | 刹车并清速度 |
| 转向电位器 | ADC11 / P3.3 | 已用 `stc8h_adc` 低频采样后归约到 0..180 度 |
| 前进/后退 | P3.7 | 低电平有效输入 |
| 灯光 | P3.6 | 低电平有效输入 |
| 蜂鸣器 | P3.5 | 低电平有效输入 |
| 单独刹车 | P3.0 | 低电平有效，刹车但不清速度 |
| Fn | P3.4 | 请求显示或回传电压 |
| TM1637 CLK | P1.7 | 已接入低亮度状态显示 |
| TM1637 DIO | P3.1 | 已接入低亮度状态显示 |

## Receiver

| 功能 | 引脚/通道 | 当前处理策略 |
| --- | --- | --- |
| 灯光 | P3.5 | 低电平有效，已接入安全态关闭 |
| 蜂鸣器 | P3.6 | 低电平有效，已接入安全态关闭 |
| LED | P3.7 | 低电平有效，已接入安全态关闭 |
| RF 频道 + | P3.0 | 低电平有效，按下后频道加一并保存 |
| RF 频道 - | P3.1 | 低电平有效，按下后频道减一并保存 |
| AT8236 IN1 | P3.3 / PWM7_2 | 已接入 10kHz PWM，安全态 0% |
| AT8236 IN2 | P3.4 / PWM8_2 | 已接入 10kHz PWM，安全态 0% |
| MOS PWM | P5.4 / PWM6_2 | 已接入 10kHz PWM，安全态 0% |
| 舵机 | P1.0 / PWM1P | 已接入 50Hz PWM，安全态回中 |
| 电池电压 | ADC1 / P1.1 | 已接入，仅 controller 请求时低频采样并回传 |
