# 重要逻辑流程

## Controller 启动和连接

```text
初始化显示、输入、SPI、nRF24
读取 EEPROM 配置
显示 Cxxx，尝试保存频道
  成功收到合法 ACK 状态 -> 进入控制界面
  连续失败超过阈值 -> 显示 Lxxx，锁定该频道重试
Lxxx 下 EC11 中键双击 -> 手动扫描预设频道池，再扫描 S000..S125
扫描找到匹配 receiver -> 显示 Fxxx，保存频道，进入控制界面
```

上电、遮挡、距离过远或短时干扰都先视为该频道链路问题。controller 不自动扫频，避免把可恢复的短时丢链误判为需要换频道。

显示语义：

| 显示 | 含义 |
| --- | --- |
| `C076` | 正在尝试频道 76 |
| `L076` | 频道 76 暂时连不上，锁定该频道重试 |
| `S076` | 手动扫描到频道 76 |
| `F076` | 找到频道 76，短暂停留后进入控制界面 |
| `E001` | controller nRF24 初始化失败 |

## Controller 正常控制

主循环约 20ms 一次：

```text
消费 EC11 速度增量
刷新按键和转向输入
应用配置校准
打包 11 字节控制 payload
生成 32 字节 proto_rf_link DATA
发送 nRF24 包
解析 15 字节 ACK 状态
刷新 TM1637
连续失败超过阈值 -> Lxxx
```

正常显示：

| 显示元素 | 含义 |
| --- | --- |
| 第 1 位 `^` / `v` | 前进 / 后退 |
| 第 1 位 `-` | 刹车或安全控制状态 |
| 第 3-4 位 `00..99`、`A0` | 速度 0..100 |
| 冒号灭 | 最近通信正常 |
| 冒号快闪 | 短时发送失败或 ACK 缺失 |

EC11 中键：

| 操作 | 条件 | 动作 |
| --- | --- | --- |
| 短按 | 正常控制界面 | 刹车并清零速度 |
| 双击 | `Lxxx` | 启动手动扫频 |
| 双击 | 非 `Lxxx` | 忽略 |
| 长按 5 秒 | 正常模式且按下前速度为 0 | 进入配置模式 |
| 长按 5 秒 | 正常模式且按下前速度不为 0 | 只清零速度，不进入配置模式 |

## Controller 配置模式

配置模式先修改 RAM 中的配置值；长按保存到 EEPROM，断电放弃未保存修改。

```text
正常模式速度为 0 时长按 5 秒 -> 进入配置模式
配置模式发包保持安全：速度 0、刹车、灯/蜂鸣器/aux 关闭
EC11 旋转 -> 修改选中的配置项
EC11 短按 -> 切换 P1/P2/P3/P4/P5
EC11 长按 5 秒 -> 保存 EEPROM 并退出
断电 -> 放弃未保存修改
```

| 配置项 | 含义 | 范围 | 默认值 |
| --- | --- | --- | --- |
| `P1` | 方向反向 | `0/1` | `0` |
| `P2` | 舵机反向 | `0/1` | `0` |
| `P3` | 舵机中位微调 | `-20..20` | `0` |
| `P4` | 中位虚位 | `3..45` | `10` |
| `P5` | 舵机端点收缩 | `0..60` | `0` |

## Receiver 启动和绑定

```text
输出进入安全态
初始化 SPI、PWM、ADC、nRF24
读取 receiver 配置
P30+P31 上电同时按下 -> 清除绑定
初始化 PRX
预装 3 个 ACK 状态 payload
进入接收循环
```

绑定规则：

```text
未绑定:
  合法 tx_id != 0 -> 保存 bound_tx_id，应用输出

已绑定:
  tx_id 匹配 -> 应用输出
  tx_id 不匹配 -> 丢弃
```

receiver 默认启用 P30/P31 运行期频道切换，同时默认保留 P30+P31 上电清绑定。P30/P31 为低电平有效运行期输入，只接受稳定按住约 0.5 秒的单键操作；双键同时按下时忽略频道切换并锁存到全部释放，避免和上电清绑定入口混淆。

预设频道池：

```text
76, 72, 68, 64, 60, 56, 52, 48,
44, 40, 36, 32, 28, 24, 20, 16
```

运行期频道切换：

```text
P30 或 P31 单键稳定按住约 0.5 秒
  -> 在预设频道池中取下一项/上一项
  -> 更新 config.rf_channel
  -> 重新设置 nRF24 RX 频道，flush RX，清 IRQ，回到 RX
  -> 输出进入安全态：电机、灯、蜂鸣器、aux 关闭，舵机保持既有安全策略
  -> LED 进入未绑定等待或已绑定等待
  -> 重新预装 ACK 状态 payload
  -> 保存 EEPROM
```

读取 EEPROM 时，receiver 只接受上述频道池内的 `rf_channel`。池外频道恢复为 `76`，配置版本和长度仍保持版本 2，已有绑定不因频道脏数据被清除。

已连接时本机切换频道按丢链/维护处理，不输出旧控制，也不设计无线协商换频。controller 会停在 `Lxxx`，用户在 `Lxxx` 下双击 EC11 中键手动扫描找回新频道。

## Receiver 输出

- AT8236 IN1：`P3.3/PWM7`
- AT8236 IN2：`P3.4/PWM8`
- AT8236 PWM-B 默认约 20.03kHz；`APP_OUTPUT_FAST_PWM_PRESCALER` / `APP_OUTPUT_FAST_PWM_PERIOD` 控制频率。
- 电机速度 `speed < 5` 时 duty 为 0；`speed >= 5` 时从 `APP_OUTPUT_MOTOR_MIN_DUTY_PERCENT` 对应的最低 duty 线性映射到 100%，默认最低 35%。
- 刹车时 IN1/IN2 同时输出 100% duty。
- 舵机：`P1.0/PWM1P`，50Hz，receiver 安全态不改写舵机 PWM，保持最后角度。
- 灯：`P3.5`，低电平亮。
- 蜂鸣器：`P3.6`，低电平响。
- LED：`P3.7`，高电平亮。
- 辅助 PWM：`P5.4/PWM6`，来自 `aux_pwm`，controller 默认发送 0。

## Receiver LED

| 状态 | LED 表现 |
| --- | --- |
| 上电启动 | 快闪 3 次 |
| 射频初始化失败 | 双闪后长停顿 |
| 未绑定等待 | 单短闪后长停顿 |
| 已绑定等待或掉线 | 慢闪 |
| 已连接 | 常亮 |
| 清除绑定 | 快闪 6 次后进入未绑定等待 |

## 安全状态

触发条件：

- 接收超时。
- 射频初始化失败。
- 持续收不到合法控制包。

动作：

```text
AT8236 IN1/IN2 duty = 0
辅助 PWM = 0
灯关闭
蜂鸣器关闭
舵机保持最后角度
继续监听，等待恢复
```

## ACK 状态回传

receiver ACK payload 只回传短状态：

```text
link_state
receiver voltage
bound tx_id
```

receiver 启动、恢复和首次绑定后用 replace 方式重置 ACK FIFO；正常收到包后追加下一份 ACK payload，不在每次 RX 后 flush TX。
