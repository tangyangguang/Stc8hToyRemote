# 节能设计

controller 和 receiver 都按电池设备处理。目标是在不破坏操控实时性和安全输出的前提下，减少无意义的无线、显示、ADC 和 PWM 活动。

## 通用原则

- 避免无节拍忙等。
- 周期任务使用软节拍或中断采样。
- 无线、显示和 ADC 按用途限频。
- 掉线时进入明确安全输出，不保持电机、灯、蜂鸣器或辅助 PWM。
- 低功耗模式必须先确认 nRF24、按键、Timer 和输出脚唤醒/保持行为。

## Controller

- 控制包约 20ms 发送一次，发送最新状态，不重发过期控制输入。
- 频道扫描只在 `Lxxx` 下由 EC11 中键双击触发，不做上电自动扫描。
- EC11 A/B 用 Timer0 ISR 固定周期采样，主循环只消费累计 delta。
- TM1637 使用低亮度并按状态刷新。
- 转向 ADC 分频采样。
- Fn 电压显示时才读取电压相关数据。

## Receiver

- 掉线或射频错误时立即进入安全输出。
- 电机速度为 0 时 AT8236 两路 duty 均为 0。
- 灯、蜂鸣器和辅助 PWM 安全态关闭。
- 电池电压只在 controller 请求时低频采样并回传。
- nRF24 保持 PRX 监听；进一步降功耗需要实测 CE、IRQ 唤醒和重新进 RX 的时序。

## 低功耗扩展前置条件

引入 idle/power-down 前必须验证：

- nRF24L01 CE/CSN/SPI 静态电平。
- nRF24L01 保持 RX、standby 或 power-down 后的恢复时间。
- Timer0、按键和 nRF24 IRQ 的唤醒能力。
- 低功耗前后 PWM 输出和 GPIO 安全态是否保持。
- 唤醒后是否需要重新初始化 SPI、nRF24 和 PWM。
