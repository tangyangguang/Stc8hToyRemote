Tx遥控端 

V2.0：
	nRF24L01模块		1个
	4位数码管中间带冒号TM1637芯片	1个

	通道1：马达方向		自复位开关，前进、后退
	通道2：马达速度		EC11旋转编码器，右转加速、左转减速，0%~100%	
	通道3：刹车		EC11旋转编码器中间按键，按下刹车并速度置0、松开不刹车
	通道4：转向		10K电位器，左旋到头表示舵机0度，右旋到头表示舵机180度，中值表示舵机90度
	通道5：灯光		自复位按钮或自锁按钮、钮子开关，接通亮灯
	通道6：喇叭		自复位按钮或自锁按钮、钮子开关，接通鸣笛
	通道7：MOS管模块占空比	10K电位器，左旋到头表示舵机0%占空比，右旋到头表示舵机100%的PWM占空比

	nRF24L01一次最多发送32位数据，约定的数据格式为：
	Byte 0: 行车马达的方向, 取值[0,  1], 0 = 前进，1 = 后退
	Byte 1: 行车马达的速度, 取值[0,100], 速度大小，值越大，速度越大
	Byte 2: 行车马达的刹车, 取值[0,  1], 0 = 未刹车，1 = 按下刹车
	Byte 3: 方向舵机的方向，取值[0,180], 表示180度舵机的方向角度值，中值是90度
	Byte 4: 开关功能, 取值[0, 1], 0 = 未按下, 1 = 按下按钮，（控制灯光）
	Byte 5: 开关功能, 取值[0, 1], 0 = 未按下, 1 = 按下按钮，（控制喇叭）
	Byte 6: PWM占空比，取值[0,100]，用于MOS管模块的PWM控制信号，表示PWM占空比

	有正常模式和配置模式两种
	正常模式：
		开机默认进入正常模式，正常遥控
		4位数码管：
			第1位数字：马达方向
			第2位数字：MOS管开关比例，显示1~9（占空比0%~99%，只显示十位数，100%显示位A）
			第3位数字+第4位数字：马达速度，0~99正常显示，100显示位A0
			中间的冒号：正常通讯不显示，nRF24L01发送数据失败未接到应答时，显示冒号。
	配置模式：
		进入：正常模式下，同时按下方向键和刹车键3秒（P37和P54），进入配置模式
		退出：配置模式下，按下喇叭按钮（P35），退出配置模式，进入正常模式
		可配置3项：
			舵机是否反向
			舵机中值
			舵机减少角度
		配置会保存到EEPROM中，掉电也不丢失


V2.1
  1，改为两个刹车功能：编码器上的按钮是刹车并且速度置零，单独的刹车按钮是按下刹车，速度不归零，松开还是执行原有速度。
  2，前进后退改为使用钮子开关（常开常关），原来是按钮按下切换方向。
  3，灯光改为自复位按钮，按下开松开关（原来是钮子开关）。
  4，配置模式下新增方向是否反转的设置
  5，配置模式进入方式改为：同时按下EC11编码器和单独的刹车键




V2.2 改动
  1，增加了P33口的电位器控制速度，原编码器不再控制速度（还能用来刹车和配置）；
  2，修改了屏幕的接口为 CLK --> P34, DIO --> P31，这样下载程序时就不用先断开4位数码管了
  3，单独刹车按钮接口为 P30
  4，增加了一个10K电位器控制马达速度，旋转编码器不再控制速度（但还能用来刹车和配置）
  5，注释了控制MOS管的代码


V2.3改动
  1，增加了Fn按键（自复位按键）和电池电压检测功能，按下显示遥控器电池电压（2接5号或7号电池）
  2，修改：nRF24L01的第8Pin（IRQ）改成了P32, P32支持中断（sbit IRQ = P3^2;）
  3，修改：马达速度的调整使用EC11旋转编码器，去掉了V2.2中的调整速度的电位器
  4，注释了控制MOS管的代码
